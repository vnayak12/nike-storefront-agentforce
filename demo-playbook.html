🏆 Why Agentforce — Your Opening Narrative

Use this 30-second pitch to frame the demo before you show anything:

"What if Nike could resolve 80% of customer service inquiries instantly — without adding headcount? Agentforce is Salesforce's AI agent platform that goes beyond basic chatbots. It reasons over your real Salesforce data — orders, loyalty tiers, cases — takes action, and learns from every interaction. Unlike generic AI solutions, everything stays inside your trust boundary: PII is masked before it touches an LLM, every decision is auditable, and your data is never used for model training. Let me show you what this looks like for Nike Customer Service."

⚡ Key Differentiators (vs. Generic AI Chatbots)

🧠 Grounded in Real Data
Generic chatbots hallucinate. Agentforce queries live Salesforce data — real orders, real loyalty tiers, real case history. Every answer is verifiable.
🔒 Enterprise-Grade Trust
Einstein Trust Layer: PII masking, toxicity detection, prompt injection defense, zero data retention. No other AI platform provides this natively.
⚙️ Actions, Not Just Answers
Generic bots generate text. Agentforce triggers real actions — initiating returns in Service Cloud, updating loyalty in Data Cloud, creating cases. It DOES things.
🔍 Full Transparency
Every AI decision is traceable: topic selection, action invocation, data retrieval, response generation. No black box — you see exactly why the agent said what it said.
📊 Built-In Analytics & QA
Session tracing, agent optimization, and structured test suites ship natively. You measure quality and catch regressions before customers do.
🌐 Deploy Anywhere
Same agent works inside Salesforce, on your website, in your mobile app, via API. Build once, deploy to every channel — including headless for full UI control.

Agent Builder — How It's Built

Show the agent's architecture: topics, actions, and configuration

🔗 Navigate to Agentforce Builder

  1. Step 1: Go to Setup → Quick Find → search "Agents"
  2. Step 2: Click Agents → find "Nike Customer Service"
  3. Step 3: Click "Open in Builder"
💡 Shortcut: You can also navigate directly via the Agentforce Builder URL if you've bookmarked it.

🗺️ What to Show on the Left Panel (Agent Definition)

Walk through the left sidebar — this is the agent's "brain":

📋 Topics (7 specialist areas)
Nike Customer Concierge (entry router) → Order Status & Tracking → Returns & Refunds → Loyalty & Membership → Policy & Product Info → Pre-Sales & Discovery → Human Escalation
💬 "Each topic is a specialist — like different departments in a contact center. The AI planner routes the customer to the right specialist."
⚡ Actions (under each topic)
Click into a topic to show its actions — these are Flows and Apex that the agent can invoke. The agent decides WHICH action to call based on the customer's intent.
📊 Variables (17 conversation variables)
Show the Variables section: customer_id, member_tier, order_status, points_balance, etc. These are the agent's working memory — it fills them in as it identifies the customer.
💬 "The agent maintains state across the conversation — it remembers who you are, your tier, your order."
🔌 Connections & Channel Config
Show the channel mappings: the agent is connected to Messaging for In-App & Web (MIAW), which enables the Salesforce embedded widget, the headless API, and the Nike storefront integration. Context variables like ContactId and RoutableId map from the messaging session.

🧠 Talking Points

→ "This is declarative, not code-first" — topics and actions are configured, not coded from scratch

→ "The planner is multi-agent orchestration" — each topic is a specialist subagent, the planner routes dynamically

→ "Actions use existing investments" — Flows, Apex, Prompt Templates your team already built

Einstein Trust Layer — Governance & Safety

Enterprise-grade AI safety built into every interaction

🔗 Navigate to Trust Layer

  1. Step 1: Go to Setup → Quick Find → "Einstein Trust Layer"
  2. Step 2: Show the Data Masking tab — PII categories enabled
  3. Step 3: Click Safety & Security tab — Toxicity Detection & Prompt Injection
💡 Shortcut: Search "Einstein Trust Layer" in Setup Quick Find to navigate directly.

🛡️ What's Enabled (Show Each)

🔒 Data Masking
ON
Names, emails, phone numbers, credit cards, SSNs, passports, IBAN codes — all masked before hitting the LLM. Also: PII, GDPR, PCI, CCPA compliance categories are enabled.
🚫 Toxicity Detection (Prompts)
ON
Scans user inputs for harmful content. Scored and logged in the audit trail.
🚫 Toxicity Detection (Responses)
ON
Scans agent outputs before they reach the customer. Blocks toxic responses automatically.
⚡ Prompt Injection Detection
ON
Detects attempts to bypass system policies or hijack the AI's behavior. Critical for public-facing agents.

📋 Where to See Audit Data

  1. Option A: Setup → Einstein Audit, Analytics, and Monitoring Setup — shows that Audit & Feedback is ON, with a "View Dashboard" link
  2. Option B: Lightning Dashboards → search "Einstein Generative AI Audit" — this is the auto-provisioned audit dashboard showing request volume, user counts, feedback, and token usage
  3. Option C: Lightning Reports → "Einstein Gen AI Audit & Feedback" folder — drill-down reports for detailed audit queries
💬 "Every single LLM interaction is logged and auditable. CISOs love this."

🗣 Talking Points

→ "Your data never leaves the Trust Boundary" — PII is masked before it goes to any LLM

→ "Zero data retention" — LLM providers can't retain or train on your data

→ "This is automatic" — no extra configuration needed, baked into every Agentforce interaction

→ "Full compliance trail" — audit every AI interaction for SOX, GDPR, CCPA, HIPAA

Analytics & Optimization

Session tracing, performance dashboards, and AI-powered optimization

🔗 Navigate to Agent Analytics

  1. Step 1: Go to Setup → Einstein Audit, Analytics, and Monitoring Setup
  2. Step 2: Show that Agentforce Session Tracing is ON — this captures every interaction
  3. Step 3: Show that Agent Optimization is ON — AI-powered improvement suggestions
  4. Step 4: Navigate to Agentforce Studio (App Launcher → "Agentforce Studio")
  5. Step 5: Click "Analytics" in the left nav to see performance dashboards
💡 Note: Analytics data comes from Agentforce Session Tracing which stores data in Data Cloud. It may take a few minutes after conversations for data to appear in dashboards.

📈 Key Metrics to Highlight

Deflection Rate
% of conversations resolved without human escalation
Session Volume
Total conversations handled by the agent
Topic Breakdown
Which topics are most common — orders, returns, loyalty
Resolution Time
Seconds vs. minutes for human agents

🔍 Agent Optimization (Deep Dive)

In Agentforce Studio, Optimization uses AI to analyze your agent sessions and surface:

→ Sessions that need attention — where the agent struggled or gave incomplete answers

→ Improvement suggestions — AI-recommended changes to topics, instructions, or actions

→ Trend analysis — recurring issues that should become new topics or actions

💬 "This is how you continuously improve — the platform tells you what to fix."

🗣 Talking Points

→ "Powered by Data Cloud" — same analytics backbone used across Salesforce

→ "Every conversation generates analytics automatically" — no separate setup

→ "Managers get visibility" — identify what customers ask most, where the agent struggles

→ "This feeds back into optimization" — continuous improvement loop
